# Fridge Roast: One Line

The program sends a single line roasting a smart fridge to `entry.txt` in the output directory. That line is the entire entry, and nothing else is submitted.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
